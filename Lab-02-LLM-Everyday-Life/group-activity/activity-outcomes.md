# Group 4 – Activity Outcomes

The deliverables required by the lab sheet, and where to find them.

| Required | Outcome |
|---|---|
| Product concept | A timetable-aware hydration app paired with a smart bottle cap that nudges students to drink at class breaks, before they get thirsty |
| Name | **Sipwise** |
| Target user | University students on packed timetables who carry a bottle but forget to drink from it (long lecture blocks, labs where bottles stay packed away, exam season) |
| Key features | Nudges at class breaks only; ESP32 smart cap that counts sips and glows amber when behind; left-behind alert; AI timetable import; AI-written nudges; manual logging; friends' streaks; campus refill map |
| Visual prototype / mock-up | App screens and hardware diagrams in the [pitch deck](../presentation/Sipwise_Group_4_Pitch.pdf) |
| Presentation | 13-slide pitch: problem, target user, product, app, hardware, how a nudge is decided, the LLM inside the product, key features |
